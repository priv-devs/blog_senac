🚧 Projeto Integrador em Desenvolvimento

PI 2026 - 3º Semestre

Sistema de Gerenciamento de Estoque e Insumos

SAMU Regional de Dourados

Parceiro: SAMU 192 - Dourados/MS
Status do Desenvolvimento 35%

Projeto em fase inicial de desenvolvimento

Desenvolvido pelos alunos do 3º semestre do curso Técnico em Desenvolvimento de Sistemas, este sistema está sendo criado para revolucionar o controle de medicamentos e insumos do SAMU Dourados.

✅ Funcionalidades planejadas:

  • Controle em tempo real de medicamentos e insumos
  • Gestão de validade e lotes com alertas automáticos
  • Relatórios gerenciais para a coordenação do SAMU
  • App mobile para conferência em campo pelas equipes
  • Integração com sistema de compras e fornecedores
  • Dashboard com indicadores de consumo

Tecnologias utilizadas:

React Node.js MongoDB React Native Python

👥 Equipe Desenvolvedora:

Guilherme Duarte, Guilherme Santos, Andrey, Arthur Chavoni, Eduardo Garcia, Renato, Jaqueline, Bruno Fonseca,

Orientador: Prof. Thiago Gimenez

Previsão de conclusão: Agosto/2026
